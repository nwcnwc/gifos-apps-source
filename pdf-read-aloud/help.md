# PDF Read Aloud

Open a PDF on this page. The app reads it one sentence at a time. The last file you opened comes back the next time, on the sentence you had reached, if the file fits (about 8 MB). Nothing is sent anywhere.

## Open a file

Press **Open**, or drag a `.pdf` onto the page. A two-page public-domain note is already here the first time, so you can press Play before you pick a file of your own.

If the file is locked, a password box appears. The password is used only to open the file on this device.

A scanned page is a picture of words. This app has no text to read from it, and it says so.

## Listen

Press **Play**. The voice reads the current sentence, then the next. The sentence is marked on the page, and the page turns when the reading moves on.

**Pause** holds the sentence. **Play** continues it. **Prev** and **Next** move one sentence. The page box jumps to the first sentence on that page.

**Speed** is passed to the voice. It applies as the next sentence is prepared.

## The voice

The voice is not inside this app. It is whatever this computer uses for Text → speech.

Install **Offline TTS** from the store if you do not have a voice yet. Leave it in your Providers folder, and assign it to Text → speech in Settings. Then come back and press Play.

If no voice is installed, or the voice fails, a message says to install Offline TTS. The app does not play a substitute sound.

## Phone

The same controls sit at the top and wrap onto a second row. The marked sentence stays in view as the page moves.

## What is saved

The last file (when it fits), the page, the sentence, and the speed. Close the app, come back, they are still there.

This copy uses Mozilla's pdf.js (Apache-2.0). It is unofficial — Mozilla did not bless it.
